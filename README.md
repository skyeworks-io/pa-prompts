# pa-prompts

Personal assistant (PA) prompts I actually use, written like requirements, with notes on why. From the [SkyeWorks](https://www.skyeworks.io) blog.

I'm a program manager, and I've found a prompt works a lot like a requirements document. Vague adjectives get vague results. Purpose, acceptance criteria and numbers get you something you can test and improve. Each prompt here has been through a few versions, and each folder explains what changed and why.

## The prompts

| Prompt | What it does | Blog post |
| --- | --- | --- |
| [News briefing](news-briefing/) | A twice-daily news briefing for holding informed conversations beyond tech | [How I Debug a Prompt Like a Program Manager](https://www.skyeworks.io/blog/debug-ai-prompt-program-manager) |

## How to use them

1. Open a prompt and copy it.
2. Replace anything in `[square brackets]` with your own details.
3. Ask your AI assistant for a sample run before you schedule anything.
4. Change one thing at a time, so you know which change helped.
